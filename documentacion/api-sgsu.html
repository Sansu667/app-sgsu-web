Cómo usar esta API

Servicios web del proyecto formativo SGSU.

El sistema permite que un cliente registre solicitudes de servicio sobre un catálogo, que un administrador las asigne a un técnico y que el avance de cada solicitud quede trazado en una bitácora.

Autenticación. Salvo el registro, el inicio de sesión y la consulta de estado, todos los servicios exigen un token JWT en el encabezado Authorization: Bearer <token>. El token se obtiene en POST /api/autenticacion/login y vence a las cuatro horas.

Formato de las respuestas. Todas las respuestas son JSON y llevan el campo exito. Las respuestas de error traen además mensaje y, cuando la falla es de validación, un arreglo errores con el detalle campo por campo.

Solicitudes

Radicación, asignación, seguimiento y trazabilidad de las solicitudes.

GET/api/solicitudestoken

Listar solicitudes

El listado se acota según el rol de quien consulta: el cliente ve solo las suyas, el técnico solo las que tiene asignadas y el administrador las ve todas. Los filtros idUsuario e idTecnico solo tienen efecto para el administrador.

Parámetros

NombreUbicaciónTipoObligatorioDescripción
estadoquerystringno

Filtra por estado.

valores: registrada, asignada, en_proceso, resuelta, cerrada, cancelada
prioridadquerystringno

Filtra por prioridad.

valores: baja, media, alta
idServicioqueryintegerno

Filtra por servicio del catálogo.

idUsuarioqueryintegerno

Filtra por cliente (solo administrador).

idTecnicoqueryintegerno

Filtra por técnico (solo administrador).
